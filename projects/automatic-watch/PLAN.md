# 自动机械腕表：首期交互机械作品

优先级：第一项。用户于 2026-10-30 指定先制作自动机械腕表，扫地机器人及基站后排。

## 1. 主题与定位

作品名暂定：**一块自动机械表，怎样把手腕的运动变成时间？**

制作可旋转、可透视、可拆解、可运行的三维腕表网页，同时提供短视频录制视图。以通用自动机械机芯为原理示意，外观自行设计，内部结构围绕真实功能建立。

首版配置：中央时、分、秒针，自动与手动上链、杠杆式擒纵与摆轮游丝。日历机构列为核心走时完成后的扩展，单独验证后加入首期完整版。

复杂度优先投入机芯层次、齿轮与轴的连接、上链传动、擒纵相位和材质细节。计划约 35–45 个可交互总成，数量在白模阶段核定。

## 2. 必须讲清的三条关系

```text
手腕运动 → 摆陀 → 自动上链传动 → 发条储能
转动表冠 → 手动上链传动 ─────→ 发条储能

发条释放能量 → 传动轮系 → 指针显示
                    ↕
              擒纵机构 ↔ 摆轮与游丝
```

摆陀用于上链，发条提供走时能量。擒纵机构控制轮系逐步释放，并向摆轮补充能量。自动上链的具体整流结构在建模前选定，不能混画不同机芯的换向轮与杠杆方案。

## 3. 模型结构

| 系统 | 重点部件 | 展示动作 |
| --- | --- | --- |
| 外装 | 表壳、表圈、表镜、底盖、密封圈、表冠、表耳与表带 | 完整外观、翻转透底、垂直展开 |
| 显示 | 表盘、刻度、时针、分针、秒针及套管 | 移开表盘与指针，观察下方传动 |
| 承托 | 主夹板、分层桥板、宝石轴承、定位柱、紧固件 | 桥板上移，显露对应轴与轮系 |
| 自动上链 | 半圆摆陀、中心轴承、选定的换向机构与减速传动 | 模拟摆动，沿上链路径高亮传递 |
| 手动上链与拨针 | 表冠、柄轴、离合/滑动齿轮、上链和拨针传动 | 切换上链/调时档位，展示传动变化 |
| 储能 | 发条盒、发条轴、发条、棘轮与止逆机构 | 发条盒局部剖开，展示卷紧与释放 |
| 走时轮系 | 各级齿轮、齿轴、秒轮与指针传动 | 按齿数比联动，展示交替转向 |
| 擒纵调速 | 擒纵轮、擒纵叉、叉瓦、摆轮、游丝及相关支承 | 慢放锁止、解锁、冲量与回摆 |
| 扩展日历 | 日期环、拨日轮、定位簧及储能/跳转组件 | 时间加速到换日区间，展示换日动作 |

齿轮有可辨识的齿形、轮辐、轴与安装层次。桥板有倒角和表面纹理，宝石轴承对应实际轮轴位置，螺丝与夹板形成安装关系。表壳与表镜呈现壁厚和边缘曲面。

## 4. 四段主要演示

1. **上链**：完整腕表翻到背面，摆陀摆动；移开遮挡，自动上链轮系逐级亮起，发条储能示意增加。
2. **走时**：镜头进入机芯，发条盒与轮系联动，切回正面观察指针。
3. **擒纵慢动作**：相机贴近摆轮、游丝、擒纵叉与擒纵轮；按统一时间慢放，突出能量补充与逐齿释放。
4. **拆解复位**：表镜、指针、表盘、桥板与总成分层展开；选中零件聚焦说明，最后合拢恢复走时。

首条视频约 45–60 秒，以“翻到背面 → 摆陀上链 → 发条储能 → 擒纵慢放 → 全表展开”形成视觉变化。日历可另做一个特写片段。

## 5. 交互

- 拖拽旋转、缩放、双击零件聚焦，正面/背面/机芯/擒纵视角快捷切换。
- 上链演示、走时、慢动作、结构拆解四个主要入口。
- 拆解进度条，单独隐藏摆陀、表盘和桥板，保留轮系参照。
- 表冠切换上链与调时，控制行为与机械档位关联。
- 时间倍率统一驱动齿轮、摆轮、擒纵和指针；界面明确显示倍率。
- 进入实体爆炸拆解前暂停；复位后恢复。透明查看可以与运行并存。
- 自动镜头和自由查看共享模型状态，支持暂停、恢复、重置及录制视图。

## 6. 技术架构

采用 **Vite + TypeScript + 原生 Three.js + HTML/CSS**。Vite 用于开发与构建；TypeScript 编译为浏览器执行的 JavaScript；Three.js 负责三维显示。首版以代码生成模型为主，构建为静态网页。

| 模块 | 职责 |
| --- | --- |
| 模型生成 | 表壳、桥板、齿轮、轴承、螺丝、发条和游丝的参数化几何 |
| 总成注册表 | 零件 ID、系统、父级、轴心、装配/拆解位姿、聚焦点和说明 |
| 运动关系 | 齿数比、转向、同轴连接、上链/拨针切换，以及擒纵事件相位 |
| 过程与时间轴 | 播放状态、上链过程、能量示意、运行时间、倍率、慢动作和重置 |
| 交互 | Raycaster 拾取、总成定位、相机聚焦、分层拆解和可见性 |
| 渲染与镜头 | OrbitControls、材质、灯光、阴影、自动镜头和录制构图 |
| 页面 | 部件索引、说明、状态、倍率、演示入口与移动端面板 |

机构运动以统一的演示时间和关系图计算。齿轮传动与擒纵使用可核对的比例和相位；储能、振幅等未建立物理求解的量明确作为示意值。完整轮系布局先确定齿数、轴距和高度，再生成可见几何。

表壳与桥板使用曲线轮廓、旋转体、拉伸和自定义网格；齿轮通过轮廓和参数生成。发条与游丝可用曲线/带状网格表达，并处理固定端与运动端的关系。

渲染优化按总成复用几何和材质。可独立运动、拆解或选中的部分保留节点；重复紧固件按所属总成实例化。

## 7. 视觉方向

主视觉为高端制表工作台：银灰桥板、香槟金轮系、红色宝石轴承、深蓝或深灰表盘，配深色背景和柔光。金属质感重点由倒角、拉丝、粗糙度与环境反射形成。

默认展示完整腕表三分之四视角。机芯展开以垂直层次为主；擒纵单独提供微距视角；竖屏录制为每段镜头重新构图。

## 8. 实施顺序与验收

1. **结构白模**：先完成主夹板、轮系、发条盒、擒纵、摆轮与摆陀布局。验收轴心、齿数比、啮合距离、层次和支承关系。
2. **运动闭环**：完成上链、走时、指针、擒纵慢动作及统一暂停/重置。验收齿轮方向与比例、擒纵锁放相位、倍率切换和恢复状态。
3. **外装与精细结构**：完成表壳、表盘、桥板、轴承、紧固件与材质，再加入可验证的日历结构。
4. **交互与镜头**：完成部件选择、拆解、说明、自动镜头和竖屏录制。验收拆解复位、无遮挡微距镜头及连贯播放。

第一步优先验证擒纵与轮系联动，它决定后续展示是否可信。
