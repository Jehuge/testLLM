# 扫地机器人及全能基站：交互拆解与短视频方案

## 1. 作品目标

制作一个可交互的 3D 原理展示网页，呈现双旋转拖布扫地机器人及其全能基站。用户可以拆开结构、查看通道、启动工作循环；同一网页提供适合录制短视频的自动镜头。

核心主题：**扫地机器人回到基站后，里面究竟发生了什么？**

画面复杂度来自能够对应工作过程的结构：风机、滤芯、密封口、泵阀、软管、清洗盘、齿轮、电机、传感器和电路板。每个关键零件都能在讲解中找到用途。

本方案采用通用功能架构，内部空间与管路按展示需要设计。它是功能原理示意，不是某个品牌的精确拆机或工程仿真。若后续指定真实机型，应依据该机型拆机资料核对内部布置、泵阀类型和运行时序。

## 2. 本期采用的配置

- 圆形机器人，顶部激光雷达，前方避障传感器，底部悬崖传感器。
- 双驱动轮、万向轮、单边刷、主滚刷、独立吸尘风机及可取出的尘盒。
- 双旋转拖布，带抬升机构、机内清水箱及供水组件。
- 水箱式基站：清水箱、污水箱、尘袋仓、集尘风机、供水组件、污水回收组件、清洗盘及暖风烘干组件。
- 基站提供自动集尘、洗拖布、机内补水、烘干与充电。

首版选定这套配置，保证对接关系和动作一致。机械臂、自动接入上下水、滚筒拖地及拖布自动拆卸可以另做扩展篇。

## 3. 结构规划

目标为约 45–55 个可交互总成。这里的“总成”指能单独选中、拆出并说明用途的模块，不等于网格数量。第一阶段核定模块边界后再确定数量。

### 机器人：约 25–30 个总成

| 系统 | 重点结构 | 拆解或运行表现 |
| --- | --- | --- |
| 外壳与底盘 | 顶盖、上壳、承力底盘、前碰撞缓冲圈 | 顶盖上移、上壳抬起，露出真实厚度、卡扣与安装柱 |
| 导航感知 | 雷达塔、前避障模组、沿墙与悬崖传感器 | 雷达扫描示意、障碍物高亮、传感器视场示意 |
| 行走 | 左右驱动轮模组、减速齿轮、悬挂弹簧、万向轮 | 转向时两轮差速；局部剖视显示减速与悬挂 |
| 扫地 | 边刷、电机、滚刷、滚刷仓、传动机构 | 边刷归拢颗粒、滚刷送入吸口，镜头切到机身底部 |
| 吸尘 | 尘盒、过滤组件、风机蜗壳、叶轮、吸入与排出风道 | 尘粒进入尘盒，过滤后的气流经过风机排出 |
| 拖地 | 左右拖布盘、织物、驱动模组、抬升机构 | 双盘旋转、拖布变脏、遇地毯时抬升 |
| 供水 | 机内清水箱、供水组件、分水管及出水口 | 清水分配到两侧拖布，水箱液位随演示变化 |
| 电控与对接 | 电池、主板、线束、充电触点、补水与集尘接口 | 电控细节可见；对接时突出接口位置和密封关系 |

### 基站：约 20–25 个总成

| 系统 | 重点结构 | 拆解或运行表现 |
| --- | --- | --- |
| 机壳与框架 | 顶盖、前盖、侧壳、内部骨架、进站坡道 | 壳体横向展开，显露上下分层布局 |
| 清水 | 可取水箱、箱盖、液位件、密封接头、供水泵阀与软管 | 水箱上提；供水分向清洗盘和机内补水接口 |
| 污水 | 污水箱、密封盖、回收管、回收组件、液位检测 | 清洗盘积水进入污水箱；具体回收结构按实现选型说明 |
| 集尘 | 对接密封口、集尘管道、尘袋、过滤件、集尘风机 | 机器人尘盒中的尘粒进入尘袋，空气通过过滤段排出 |
| 拖布清洗 | 可抽出清洗盘、清洗筋、喷淋口、过滤网、排水槽 | 拖布在清洗盘内旋转摩擦，污渍渐退、污水汇集 |
| 烘干 | 风机、加热组件、保温/隔热结构、分流风道、底部出风口 | 暖风抵达拖布与盘体，拖布湿度示意逐渐下降 |
| 充电与控制 | 电源模块、控制板、线束、充电触点、回站信标 | 充电接触后显示状态，控制板与各执行件关联高亮 |

### 细节要求

- 水箱有壁厚、箱盖、提手和密封圈，液面位于箱体内部。
- 尘袋体现织物、接入口和承托空间，清楚区分袋内尘粒与袋外气流。
- 轮胎有纹理，拖布有纤维感，滤芯有褶皱，风机有叶轮与蜗壳。
- 管路具有接头、弯曲半径、固定夹和起止端；穿越结构时必须留孔。
- 螺丝、散热孔、卡扣、线束连接器用于增强可信度，按实际需要布置。
- 透明模式保留外轮廓，避免水箱、机壳、管道与内部件叠成一团。

## 4. 四套可以追踪的路径

颜色同时搭配文字、箭头和方向动画，不仅依赖颜色区分。

1. **吸尘与集尘路径：米金色颗粒、浅灰气流。** 清扫时，地面颗粒经刷头和吸口进入尘盒，空气经过滤后由机器人风机排出。集尘时切换到基站路径：尘盒 → 对接集尘口 → 基站尘袋；颗粒停留在尘袋内，过滤后的空气继续通过风机与排气段。
2. **清水路径：青蓝色。** 清水箱 → 供水组件 → 分支阀路 → 清洗盘喷淋口；另一支路经对接接口为机器人清水箱补水。两个过程按所选演示阶段调度。
3. **污水路径：灰棕色。** 清洗盘 → 过滤与排水口 → 回收管 → 污水箱。普通旋转拖布在地面携带污渍，回站后洗出污水；不要画成机器人在地面吸走污水的滚筒洗地架构。
4. **烘干路径：淡橙色。** 进气 → 烘干风机 → 加热段 → 风道 → 拖布与清洗盘 → 排出。以流线表示暖风，用湿度变化表达烘干效果。

集尘气路、烘干气路与水路分别建模。尘粒不能穿过滤材；污水不能进入清水箱；加热器和电子部件的空间布置应能解释防水与隔热关系。

污水回收若采用负压方案，应画出气泵连接污水箱气相空间的气路，并区分它与液体回收管；若采用液泵方案，应明确其为本示意模型的设计选择。不得混画两种原理。

## 5. 一键自动演示

| 阶段 | 机器人与基站动作 | 镜头与信息 |
| --- | --- | --- |
| 出站 | 从基站出发，刷头与拖布启动 | 整机三分之四视角，建立尺寸与位置关系 |
| 扫拖 | 扫过少量颗粒和一块污渍 | 低机位跟随，切到透明底盘观察尘路和拖布 |
| 回站 | 接近信标，转向并对准接口进入基站 | 相机靠近坡道，展示触点、集尘口、补水口对位 |
| 集尘 | 基站风机启动，机内尘盒清空，尘袋接收灰尘 | 基站外壳渐隐，沿集尘管道追踪颗粒 |
| 洗拖布 | 清水喷入清洗盘，拖布旋转，污水回收 | 下方侧剖视，跟踪清水、污水两条路径 |
| 补水 | 基站向机内清水箱补水，达到演示目标后停止 | 接口特写，两个水箱液位联动 |
| 烘干与充电 | 供水停止、盘内排水完成，暖风开启；充电状态显示 | 暖风流线穿过拖布，镜头拉回整机 |

这个顺序是为内容讲解编排的演示脚本，实际产品可能采用不同顺序、并行执行或在出站前洗拖布。长时间过程统一压缩，并在页面标注“过程加速演示”。

回站采用固定的、可以验证的路线，体现转向与精确对位；首版导航扫描和路径图为预设示意动画。真实定位算法与流体/热力计算不属于首版范围。

## 6. 交互设计

### 四个主要入口

- **自动演示**：一键播放完整循环，支持暂停、继续、重置和阶段跳转。
- **结构拆解**：分别拆机器人或基站；拆解进度 0–100%；点击总成局部移出并聚焦。
- **通道透视**：吸尘/集尘、清水、污水、烘干四个开关，当前工作通道自动突出。
- **录制视图**：隐藏操作面板，保留标题与当前阶段说明，提供竖屏构图。

### 通用操作

- 拖拽旋转、缩放、双击部件聚焦，一键回到全景。
- 快捷视角：整体、机器人底部、机器人内部、基站剖面、对接接口。
- 点击部件：高亮、短说明、所属系统、工作时机；“查看工作过程”跳转对应演示阶段。
- 壳体透明度独立控制；标签按当前系统筛选，同屏优先保留 4–6 个。
- 运行时支持透视。进入实体爆炸拆解前暂停运行；合拢后可从已保存阶段恢复。
- 首版提供一个异常示范：“清水不足 → 停止洗拖布并高亮清水箱”。更多异常后续增加。

## 7. 画面设计

### 整体方向

精密家电实验室：珍珠白机身、石墨灰内框、金属电机、半透明烟灰水箱。深石墨色摄影棚背景为默认，辅以浅色检视模式。灯光用大面积柔光形成轮廓和材质层次。

颜色集中用于当前运行通道与选中部件。零件保留塑料、橡胶、织物、金属与电路板的自然材质。

### 默认构图

- 基站位于画面中后方，机器人位于前方偏左，三分之四视角。
- 基站剖开展示时，清水箱、污水箱、尘袋和底部清洗区形成可辨认的层次。
- 机器人底盘采用专门检查视角，保证滚刷、双拖布、轮组都能看清。
- 全局拆解同时区分方向：机器人以垂直分层为主，基站以左右展开为主；为标签与相机预留空间。
- 9:16 录制时改为上下构图或单机特写，避免把宽屏画面直接裁小。

### 页面信息

左上：作品名“扫地机器人与全能基站”及当前阶段。

中间：以 3D 模型为主，默认不铺设大块图表。

右侧：可折叠部件说明，显示短句和必要示意。

底部：阶段时间轴、播放/暂停、结构拆解、通道透视、录制视图。

数值只用于说明当前阶段，例如清水余量、污水液位、尘盒装载与电量；统一标注“演示值”，不给没有依据的实际吸力、温度或性能指标。

## 8. 约 50 秒的首条视频

| 时间 | 画面 | 字幕/口播主意 |
| --- | --- | --- |
| 0–4 秒 | 机器人回站，基站外壳迅速变透明 | “扫地机器人回家以后，基站里面到底在忙什么？” |
| 4–10 秒 | 机器人与基站展开，快速呈现内部结构 | “尘袋、水箱、风机、泵阀和管路，都藏在这里。” |
| 10–18 秒 | 合拢后沿集尘管道追踪颗粒 | “先把机内尘盒里的灰尘，送进基站尘袋。” |
| 18–31 秒 | 清洗盘特写，清水喷出、拖布转动，污水进入污水箱 | “再洗拖布。清水进来，污水收走，两条路要分清。” |
| 31–38 秒 | 补水接口特写，机内清水液位上升 | “机内的小水箱，也在这里补充。” |
| 38–45 秒 | 暖风通道亮起，拖布湿度下降 | “最后用暖风把拖布和清洗盘吹干。” |
| 45–50 秒 | 点击展开风机或拖布驱动，拉回整机 | “这一整套过程，能拆开看，也能自己操作。” |

录像阶段压缩实际等待时间。可制作另一条偏机械细节的短片，专看滚刷、轮组、双拖布齿轮与基站风机。

## 9. 制作顺序与验收

### 第一步：结构白模与空间验证

交付机器人与基站的可旋转白模，先确定机身比例、分层、总成与管道布置。锁定回站方向，使触点、集尘口、补水口和洗拖布位置能同时对齐。

验收：机器人能进出基站；所有关键接口有对应端；水箱可取出；尘袋可抽出；拆解后无严重交叠；关键内部结构有查看角度。

### 第二步：核心工作流程

实现出站扫拖、回站、集尘、洗拖布与回收污水、补水、烘干，以及对应透明剖视、流线、液位与状态控制。

验收：阶段可以单独进入、暂停和重置；尘粒与液体去向正确；未对接时不启动集尘/补水；过程结束后资源与运动正确停止；重复播放不累积多余对象。

### 第三步：材质、拆解与交互完善

补齐软管接头、密封圈、齿轮、电机、滤材、织物、线束及适量紧固件；完成局部聚焦、总成说明、拆解进度和清水不足示范。

验收：总成身份与说明一致；拆解可往返，复位准确；管线不会无故悬空；爆炸拆解与运行状态切换稳定。

### 第四步：录制与展示优化

完成自动镜头、录制视图、竖屏构图、暗浅主题，以及性能适配。

目标：常用桌面设备流畅交互；普通移动设备自动降低粒子、透明叠层、阴影与几何细节。实际帧率在目标设备上测量后记录。

验收：完整自动演示可连续播放；竖屏关键部件不被裁切；说明不挡模型；在录制视图下能直接获得一条连贯素材。

## 10. 实现建议

- 3D 使用 Three.js；模型允许程序化几何与有许可的 glTF 资产混合，按关键结构的形状需求选择。
- 外壳、蜗壳、叶轮、拖布驱动等核心结构优先保证轮廓与比例；通用紧固件可复用。
- 总成统一保存装配变换、拆解变换、聚焦点、系统标签和简短说明。
- 使用显式阶段状态机管理电机、泵阀、风机、粒子、液位与镜头；录制与自由观察共享同一过程状态。
- 自动镜头可暂停，自由观察后支持恢复预设构图。
- 对透明水箱、软管、外壳进行独立排序与遮挡检查；流动效果采用可重复的示意动画。
- 性能优先采用复用几何、实例化细节与有限粒子；以实际画面和测量决定细节规模。
